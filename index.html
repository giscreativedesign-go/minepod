Siap Deploy: Supabase & Vercel

⚙️ Konfigurasi Database Supabase

Aplikasi MinePod dapat langsung disinkronkan ke Supabase (PostgreSQL + Realtime). Jika dideploy di Vercel, konfigurasi ini otomatis terbaca melalui Environment Variables (SUPABASE_URL dan SUPABASE_ANON_KEY).

Langkah Cepat Setup Supabase:
  1. Buat project di supabase.com.
  2. Buka menu SQL Editor, lalu jalankan isi file supabase/schema.sql.
  3. Salin Project URL dan anon public key dari Project Settings > API.

📥 Cadangan Data & Reset

Salin teks JSON di bawah untuk menyimpan cadangan manual seluruh episode, tamu, peralatan, risiko, KPI, QCC, dan Fishbone. Anda juga dapat menempelkan teks cadangan lama lalu menekan tombol Muat Cadangan.
